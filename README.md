# AI-Student-Performance-Predictor
AI Student Performance Predictor

AI Student Performance Predictor is a machine learning and AI-powered web application developed with Python and Streamlit to predict student academic outcomes and provide intelligent academic support.

# Features
      Student performance prediction
      Weak subject analysis
      AI-generated recommendations using Gemini AI
      Multilingual support
      Voice/audio recommendations
      Interactive performance dashboard
      Risk analytics
      PDF report generation
      Data visualization with Plotly

# Technologies Used
      Python
      Streamlit
      Scikit-learn
      Plotly
      Gemini AI
      gTTS
      Pandas
      NumPy
